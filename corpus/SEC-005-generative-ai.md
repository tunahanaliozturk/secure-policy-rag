# Use of Generative AI Tools

## 1. Approved tools only
Employees may only use generative AI tools that appear on the approved tools list maintained by IT Security. Public chatbots on personal accounts are not approved.

## 2. Data that may not be entered
Customer data, personal data of colleagues, confidential or restricted information and source code may not be entered into any AI tool that is not approved for that classification.

## 3. Human review
Output from an AI tool is a draft. The employee who uses it is responsible for checking it before it is sent to a customer or used in a decision.

## 4. Reporting
Report any accidental disclosure of data to an AI tool as a security incident through https://intranet.bank.example/security/report.
